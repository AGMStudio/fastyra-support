# Fastyra — privacidad y soporte

Sitio estático, sin cookies, analítica, fuentes remotas ni JavaScript, preparado
para las URL públicas de privacidad y soporte de Fastyra 1.0.

Sitio público: `https://agmstudio.github.io/fastyra-support/`

Canal de soporte y privacidad: `https://github.com/AGMStudio/fastyra-support/issues/new`.
Las incidencias son públicas; las páginas avisan de no incluir historial de ayunos,
archivos exportados, información de salud ni otros datos sensibles. No se promete
un tiempo de respuesta.

## Rutas preparadas

| Idioma | Privacidad | Soporte |
|---|---|---|
| Inglés | `/en/privacy.html` | `/en/support.html` |
| Español | `/es/privacy.html` | `/es/support.html` |
| Alemán | `/de/privacy.html` | `/de/support.html` |
| Francés | `/fr/privacy.html` | `/fr/support.html` |

`index.html` ofrece un selector manual de idioma. No detecta ni almacena la
preferencia de la persona.

## Publicación

El contenido se publica desde la rama predeterminada mediante GitHub Pages
(despliegue heredado desde rama, sin GitHub Actions). El repositorio público debe
contener únicamente estos archivos estáticos y no debe incluir código de la app.

Antes de una nueva versión, hay que volver a contrastar la política con el
archive exacto enviado a revisión y con la captura dinámica de red. Si una
revisión legal o un territorio exige más datos del responsable, solo deben
añadirse datos reales y confirmados.
